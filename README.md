# Credit-Risk-Analysis-
End-to-end credit risk analysis on 32,580 real loan records (Kaggle). Finds what drives default (loan-to-income, grade, income, housing, prior default), builds a 6-flag risk scorecard, compares ML models (AUC 0.93) and includes a Streamlit app that predicts default risk for a new applicant. Python, Pandas, Scikit-learn.
